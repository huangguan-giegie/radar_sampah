# Project Scope — Idea 1 Version 2

## Decision source

On 13 August 2026 the Team 04 WhatsApp vote recorded four votes for **Idea 1 Version 2** and two votes for **Idea 1**. The follow-up discussion refined the direction: marine litter is the main line, with one reporting flow; marine-life data is an OBIS map layer, not a second reporting flow.

## Problem

People may see marine litter but lack a simple way to report where it occurs and why an area may deserve attention. Existing public data can also be difficult to explore without a clear map view.

## User journey

1. Open the selected coastal-area map.
2. Submit one litter observation with a category and approximate location.
3. Review the observation before saving it.
4. See the observation with public marine-life context from an OBIS layer.
5. View an illustrative priority explanation for possible clean-up planning.

## MVP acceptance boundary

- One coastal area.
- One reporting flow for marine litter.
- A small, agreed category list.
- Public or synthetic data only.
- Location masking for sensitive species data.
- Transparent labels for demo classification and priority logic.
- No claim of verified species identity, pollution-source proof or regulatory action.
