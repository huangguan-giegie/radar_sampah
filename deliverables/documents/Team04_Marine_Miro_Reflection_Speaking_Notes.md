## Huang Guan — personal reflection — about two minutes

As PM, I coordinated scope, the GitHub workflow, Drive evidence and the Render demo. I learned that the hardest part was keeping documents, code and deployment aligned while the idea became more focused.

My next SMART goal is to review every active branch within 24 hours, record the decision and run one integrated test after each merge. Success means each active task has an owner and next action, and no active branch is left unreviewed for more than one day.
