## Matching and precision

Each row was checked against the original BeachSearcher record and its state, island, nearby settlement and neighbouring beaches. Government named-beach gazetteers, first-party tourism maps, published beach research, mapped OpenStreetMap beach features and public Google Maps place markers supplied the coordinates. Google place coordinates and CID identifiers were read from public links or embedded maps; viewport centres were excluded. A resort marker is accepted only as an explicitly approximate reference to its corresponding beachfront, rather than a survey of the beach boundary.

Island centres, city centres, offshore dive points, unmatched names and contradictory place identities were not substituted. Multiple Malaysian beaches can share an English name. Administrative discrepancies between the provider and official sources are recorded in the row evidence.

The school Google Workspace account disables the interactive Maps service. Public tourism map links and publicly accessible embedded place records were used where available; the account and its settings were not changed.

OpenStreetMap-derived data is attributed to [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) under ODbL. Public geographic facts and source links are recorded; provider reviews, photographs and descriptive content are not copied into the application.

## Database and application behaviour

Startup refreshes only the 82 managed catalogue rows, updating changed latitude, longitude and area values in one database batch. The four MVP records, stable identifiers, reports, photos, users, events, attendance, cleanup history and biodiversity reference rows are preserved. Restarting with the same catalogue performs no location writes. New deployments therefore update previously seeded null coordinates, rather than merely changing the local JSON file.

The existing 25 km GPS resolution and event proximity rules continue to apply. All 82 export rows now have a coordinate reference and can participate in location-based map/model flows. Approximate and triangulated references remain explicitly labelled so they are not represented as exact surveyed beach centroids. Public Insights retains its four-beach scope and existing minimum-evidence/privacy rules.
