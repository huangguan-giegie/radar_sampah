# Radar Sampah - Analysis Notes

- The active flow is report, confirm, heatmap, mission, evidence and progress.
- Recognition uses a labelled local demo fallback unless the team explicitly
  enables a private provider. It is not a verified model result.
- Severity and cleanup priority use simple transparent rules for the demo.
- Heatmap values are grouped by broad area and marked approximate.
- Before/after impact is illustrative. It does not prove cleanup success or an
  ecological change.
- The product does not identify pollution sources, expose sensitive positions,
  or make legal or enforcement decisions.
- The five categories, area catalogue and API contract are in `API.md` and
  `PROJECT_SCOPE.md`.
